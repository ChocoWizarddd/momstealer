## A cinematic, dark-themed music player for Android

NightLight is a beautifully designed music player focused on:
- **Smart Shuffle** with genre-aware queue generation
- **Normal Shuffle** with stable full permutation
- **Genre hierarchy** using provider metadata + album heuristics + artist heuristics
- **Explicit mood support** that respects genre boundaries
- **Physical device tested** playback experience

## ✨ Features

### Smart Shuffle Engine
- **Hard tier gating**: SAME_GENRE (70-80%) → RELATED_GENRE (15-25%) → DISCOVERY (0-10%) → UNKNOWN FALLBACK
- **Mood-aware**: Explicit mood (LOVE, ENERGY, CALM) influences ranking within the musical neighborhood
- **Sequential continuity**: No track repeats in positions 1-5 when alternatives exist
- **Version family gating**: Only ONE version family member per 20-track queue
- **Artist/album cooldowns**: No immediate repeats, max 2 in previous 4 positions

### Genre Classification Hierarchy
- **PROVIDER** (0.95): Trusted metadata from music providers
- **ALBUM_HEURISTIC** (0.65): Album name-based genre detection
- **ARTIST_HEURISTIC** (0.55): Artist name-based genre detection  
- **FALLBACK** (0.0): Unknown genres classified as UNKNOWN with confidence=0

**UNKNOWN is never SAME or RELATED** - it's always FALLBACK with confidence=0.

### Shuffle Order (canonical `ShuffleOrderFactory`)
- **Normal**: stable full permutation (uniform Fisher–Yates), built once
- **Smart**: several complete seeded permutations are generated by constrained placement (same-artist/same-song adjacency avoided whenever an alternative exists, relaxed automatically when the pool leaves no choice); each candidate is scored on soft diversity terms — artist spacing, album spacing, genre diversity, title similarity, freshness, recent plays — and the best-scoring candidate is returned
- Track uniqueness is the only hard rule: a pool that cannot be spread (e.g. 12 tracks, 5 from one artist) still produces a complete, valid order — soft preferences relax, nothing is rejected
- Every track plays exactly once per cycle; the order never regenerates except on an explicit reshuffle, a new source, or a genuinely exhausted cycle
- Media3 shuffle stays OFF so the app's permutation order is respected
- No recommendation engine interference

### Playback & Queue Management
- Media3-based playback pipeline
- Autoplay on queue end
- Sleep timer
- Playback history tracking
- Listen Together chat integration

### Account & Profile
- Guest mode: "Not signed in" state
- Logged in: Circular avatar (112dp), username, email, Sign Out
- ShapeableImageView + Glide circleCrop for profile photos
- Account remains rightmost footer item

## 🛠️ Development

### Build Commands
```bash
# Debug build (signed with debug key, ready for testing)
./gradlew assembleDebug

# Release build (unsigned, needs production keystore)
./gradlew assembleRelease

# Run all tests
./gradlew testDebugUnitTest

# Lint check
./gradlew lint
```

### Project Structure
```
android/app/src/main/java/com/nightlight/app/
├── playback/             # PlaybackSession, PlaybackEngine, PlaybackContext(s)
├── shuffle/              # ShuffleOrderFactory, QueueManager, ShuffleCoordinator
├── smartshuffle/         # GenreHelper, TitleGuard, SmartShuffleEngine (radio batches)
├── player/               # PlaybackManager (Media3 wiring)
├── data/                 # Data layer & repos
├── domain/               # Domain models (Track, GenreInfo)
├── ui/                   # UI components & activities
└── res/                  # Resources & layouts
```

### Key Files
- `ShuffleOrderFactory.java` - The ONE canonical shuffle: plain (Fisher–Yates) + smart (multi-candidate, soft-penalty score-select)
- `PlaybackSession.java` - Frozen order + cursor for one playback context
- `QueueManager.java` - Queue composition, manual Play Next, idempotent refill
- `SmartShuffleEngine.java` - Orders fresh radio/recommendation batches in Smart mode
- `GenreHelper.java` - Genre hierarchy & classification
- `Track.java` - Track model with genre/language fields
- `SettingsActivity.java` - Account/Profile management
- `ListeningContext.java` - Mood detection & blending
